## 🚀 Features
- **Offline Transcription:** Powered by OpenAI Whisper via OpenVINO for local inference.
- **Hardware Accelerated:** Optimized specifically for **Intel Arc™ Graphics**.
- **Privacy First:** No audio data leaves the local machine.
- **Automated Reporting:** Generates a professional PDF assessment instantly.

## 🛠️ Setup
1. Install requirements: `pip install -r requirements.txt`
2. Install [wkhtmltopdf](https://wkhtmltopdf.org/downloads.html).
3. Run the application: `python final_app.py`
